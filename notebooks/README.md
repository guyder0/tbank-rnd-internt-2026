# Исследовательский анализ KION

Два анализа помогают понять, какую информацию содержит история пользователя
и как её длина связана с качеством рекомендаций.

## Качество данных пользователей

`user_quality_eda.ipynb` содержит таблицы, графики и примеры историй.
`user_quality_eda.html` — готовая HTML-версия, которую можно открыть без Jupyter.

Основной анализ использует только историю до 9 августа 2021. Проверяются
повторы, необычная активность и похожие истории. Диагностические флаги не
используются для автоматического удаления пользователей из обучения.
Количество фильмов с одной датой последнего просмотра нельзя считать числом
сеансов или достоверным признаком бота.

## Длина истории и разреженность

`interaction_density_eda.ipynb` и `interaction_density_eda.html` показывают
распределение длины историй, плотность user–item матрицы, потери данных при
пороговой фильтрации и качество сохранённого baseline по группам пользователей.

Этот анализ использует готовые validation-предсказания; модели не переобучаются.

## Воспроизведение

После установки зависимостей из корня проекта:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 baseline/.venv/bin/python \
  scripts/execute_eda_notebook.py

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 baseline/.venv/bin/python \
  scripts/execute_eda_notebook.py notebooks/interaction_density_eda.ipynb
```

Скрипт выполняет Python-ячейки, сохраняет результаты и строит HTML без
Jupyter-сервера. Для интерактивной работы откройте notebook в Jupyter с
подходящим Python kernel.

Подробные таблицы находятся в `baseline/artifacts/eda_users_20210809/` и
`baseline/artifacts/eda_density_20210809/`. Они локальные и могут отсутствовать
в свежей копии репозитория.
