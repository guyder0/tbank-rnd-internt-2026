# Генеративные рекомендации через Semantic IDs

Рекомендатель предсказывает код фильма по истории пользователя. В отличие от
baseline, перед нейросетью нет списка кандидатов, собранного ручными правилами:
beam search ищет вероятные коды в фиксированном каталоге фильмов.

## Модель

```text
Метаданные → текстовые векторы → RQ-VAE → Semantic ID фильма
История SID и давность → encoder-decoder Transformer → SID → фильм
```

RQ-VAE переводит вектор фильма в latent размерности 32 и квантует его тремя
словарями. В каждом 64 центра; дополнительный четвёртый код устраняет коллизии.
В истории генератора embeddings четырёх кодов фильма суммируются. Decoder
предсказывает SID авторегрессионно, а trie запрещает несуществующие коды.

Это адаптация TIGER, не полное воспроизведение статьи. В частности, представление
истории и обучающий протокол отличаются. Каталог содержит 14947 объектов,
известных до первого train cutoff; будущие объекты вне каталога не удаляются
из знаменателей метрик. Ранее просмотренные фильмы не рекомендуются.

## Результаты

Validation: 3328 тёплых пользователей, 9–16 августа 2021, seed 42.

| Представление и tokenizer | NDCG@10 | Recall@10 | MAP@10 |
|---|---:|---:|---:|
| Популярность | 0.12330 | 0.18897 | 0.08363 |
| TF-IDF/SVD + residual k-means | 0.13568 | 0.19986 | 0.09512 |
| **TF-IDF/SVD + RQ-VAE** | **0.14054** | **0.20995** | **0.09785** |
| Sentence-T5 + RQ-VAE | 0.13651 | 0.20084 | 0.09617 |
| E5-base + RQ-VAE | 0.13593 | 0.20333 | 0.09528 |
| E5-base + alternating/affine RQ-VAE | 0.13512 | 0.20125 | 0.09439 |
| CatBoost strong/expanded, CPU | 0.16041 | 0.23361 | 0.11351 |

Лучший генеративный вариант превосходит популярность, но не ручной baseline.
Меньшая reconstruction loss и большее разнообразие SID не гарантировали
улучшения рекомендаций. Это результаты выбора на одной validation-неделе;
новый независимый test для всей серии не проводился.

## Как запустить

Для обучения и внешней оценки на другом компьютере используйте
[generative_docker](../../generative_docker/README.md). В нём закреплён лучший
TF-IDF-рецепт; языковые модели скачивать не требуется. Подготовка окружения и
общих CSV описана в [корневом README](../../README.md).

Исторический запуск на исходных KION cutoffs:

```bash
baseline/.venv/bin/python -u -m research.generative_recsys.run --device cuda \
  --config research/generative_recsys/configs/best_tfidf_rqvae.json
```

Он требует исходный архив, распакованные метаданные и dev-user sample,
создаваемый `baseline.pipeline run`. Для маленькой проверки добавьте `--smoke`
и замените устройство на `cpu`. Подробные команды — в [RUNNING.md](RUNNING.md).

`configs/default.json` оставлен для исследования E5-base и отличается от лучшего
рецепта. Изолированное обучение RQ-VAE запускается через `run_rqvae.py`;
параметры и варианты — в [RQ-VAE experiments](docs/RQVAE_ONLY.md).
