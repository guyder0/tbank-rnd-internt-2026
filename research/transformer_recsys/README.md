# Трансформеры в рекомендательных системах: обзор

Материалы о переходе от ручных признаков и коллаборативных методов к обучаемым
представлениям истории, retrieval, нейронному ранжированию и генеративным
рекомендациям. Обзор составлен 24–25 октября 2026 года по статьям, инженерным
публикациям и репозиториям авторов.

Практическая реализация проекта находится в
[generative_recsys](../generative_recsys/README.md). В этой папке — литература,
профиль датасета и первоначальный план отдельного reranking-эксперимента.

## Какие задачи нужно различать

| Подход | Что меняется |
|---|---|
| Transformer representations → CatBoost | Ручные входные признаки заменяются обучаемыми |
| History encoder + candidate attention | Меняются признаки и ранжировщик, кандидаты сохраняются |
| Generative Semantic IDs | Модель сама получает рекомендации через генерацию кодов |

Первоначальный план предполагал ранжирование тех же кандидатов, что у baseline.
В реализованной исследовательской ветке выбран третий вариант. Поэтому текущие
результаты сравнивают целые системы, а не только способы получения признаков.

Обзор отражает доступные публикации; заявленные авторами индустриальные результаты
не являются собственными измерениями этого проекта.

## Повторить профиль данных

Из корня проекта, после подготовки Python-окружения и KION:

```bash
baseline/.venv/bin/python -m research.transformer_recsys.src.profile_data
```

Профиль помогает оценить длину историй и неоднозначность порядка внутри одного дня.
Само ранжирование по первоначальному плану здесь не обучается.
